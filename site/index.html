Put them to work in Claude Desktop, on your own AWS account

  1. Connect Claude to AWS

    Install Claude Desktop on the showroom computer and point it at Amazon Bedrock: region, model, sign-in. No server to run.

  2. Add the assistants

    Upload the plugin with both assistants under Customize, Plugins. One assistant alone uploads under Skills.

  3. Paste a message

    Claude picks the matching assistant and returns the draft and the note. Nothing is sent until you send it.

Claude can connect to your AWS account. Model access, region and data settings are checked during setup.

The examples above were recorded on 12 October 2026 with Claude Code on a Claude subscription (model claude-sonnet-5-5), in an empty folder with only this plugin added. They were not run on Bedrock, where the wording will differ. The same plugin file passes Claude Code's plugin check and loads there; Claude picked a fitting assistant for all seven sample messages, one of them written in French and answered in French. A file edited on this page (shorter, no note) was loaded into Claude Code and changed the reply as expected. It has not been tried in Claude Desktop yet.
